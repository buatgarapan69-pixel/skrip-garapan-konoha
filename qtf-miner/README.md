# QTF Miner

Mining QTF gratis di Telegram.

- 0,8 QTF/jam, +5 QTF per tugas, +10 QTF per referral terverifikasi
- Min WD 100 QTF (~0,1 TON) ke wallet TON, fee 0
- **WD pertama 100 QTF = 0,1 TON SUDAH LANDING (25 Nov 2026) — payout TERBUKTI BAYAR.**
- Gratis, tanpa deposit.

## Cara pakai

```bash
pip install telethon requests
python3 qtf_umum.py
```

Buka file-nya dulu, isi API_ID + API_HASH kamu (dari https://my.telegram.org/apps)
dan TON_WALLET (alamat TON kamu, mis. dari Tonkeeper).
REF_CODE boleh dikosongkan (atau isi ID Telegram teman yang mereferensikan kamu).
