## Cara pakai (Termux)

```bash
pkg install python -y
pip install telethon
git clone https://github.com/buatgarapan69-pixel/skrip-garapan-konoha
cd skrip-garapan-konoha/kukdoo
python3 kukdoo_umum.py
```

Lalu pilih menu di dalam skrip:

- `[1]` Daftar + login — isi dulu `REF_CODE` (user id Telegram pemberi
  referral, boleh kosong) dan buat `apicred.json` dari https://my.telegram.org
- `[2]` Cek saldo
- `[3]` Klaim harian (gift + daily + 250 tap + WD kalau sudah dibuka)
- `[4]` Keluar

Isi `WD_ADDRESS` (alamat TON kamu) sebelum WD bisa diajukan.
