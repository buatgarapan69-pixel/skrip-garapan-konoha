# MasaBox

Buka kotak hadiah gratis di Telegram (@MasaBoxes_Bot), kumpulin STAR, WD kalau sudah cukup.

- Min WD 25 STAR
- Gratis, tanpa deposit
- Verifikasi nomor HP lewat tombol "share phone" bawaan Telegram (kirim kontak sebagai balasan ke pesan verifikasi bot)

## Cara pakai

```bash
pip install telethon
python3 masabox_umum.py
```

Buka file-nya dulu, isi `REF` dengan ID Telegram kamu sendiri (atau kosongkan),
serta API_ID + API_HASH kamu (dari https://my.telegram.org/apps).
