# ViceHood RH

Daftar waitlist ViceHood RH — gratis, tanpa deposit, tanpa connect wallet.
Supply 3.333 slot.

## Cara pakai

```bash
pip install requests
python3 vicehood_umum.py
```

Buka file-nya dulu, isi X_NAME (nama X tanpa @, maks 15 karakter)
dan EVM_ADDRESS (alamat EVM kamu, 0x + 40 hex).

Skrip cek posisi antrean kamu — server langsung kasih nomor posisi.
Jangan lupa kerjakan juga 3 tugas X di situsnya (follow, RT, quote).
