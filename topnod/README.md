# TopNod

Game mining gratis — daftar pakai email sementara, main, kumpulin hadiah.

- Gratis, tanpa deposit
- Pendaftaran pakai email sementara (API email generator — alamatnya dibuat otomatis oleh skrip)
- Jangan pernah pakai email utama kamu buat garapan seperti ini

## Cara pakai

```bash
pip install requests
python3 topnod_email.py
```

Ikuti instruksi di dalam skrip. Isi kode referral kamu sendiri kalau punya
(atau kosongkan). Jangan masukkan password / data pribadi apa pun ke dalam skrip.
