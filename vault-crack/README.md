# Vault-Crack (Free Mint NFT)

Skrip buat mint NFT Vault-Crack sendiri. Gratis, value 0 (cuma bayar gas).

Skrip cek dulu sebelum mint: mint buka, gratis, dan alamat kontraknya
terverifikasi (Sourcify exact match).

## Cara pakai

```bash
pip install web3 eth-account
export PRIVATE_KEY="0x..."
python3 vault_mint_public.py
```

Isi PRIVATE_KEY dengan kunci wallet kamu lewat environment variable —
**jangan pernah tulis private key di dalam file, dan jangan pernah kirim
private key / seed phrase ke siapa pun.**
