# Dracoria

Bonus 1 GRAM, beli Dragon Egg, klaim harian + tugas. Tanpa deposit.

- Min WD 2 GRAM
- WD belum terbukti cair

## Cara pakai

```bash
pip install telethon
python3 dracoria_public.py
```

Buka file-nya dulu, isi API_ID + API_HASH kamu (dari https://my.telegram.org/apps)
dan REF_CODE (ID Telegram kamu), lalu jalankan.
