## Cara pakai

```bash
pip install telethon requests
python3 ms_umum_public.py
```

1. Ambil `API_ID` + `API_HASH` di https://my.telegram.org/apps, isi di bagian KONFIG.
2. `REF_CODE` opsional — kode referral pengundang (mis. `ref_xxxx`), boleh kosong.
3. Login pakai nomor HP Telegram + kode OTP yang dikirim Telegram.
4. Skrip akan: `/start` bot → join channel + grup tugas → start 6 bot tugas → daftar di Mini App → klaim 9 tugas resmi → tampilkan tiket + link referral kamu.
5. Desert trip tidak bisa otomatis (butuh nonton iklan di WebView) — mainkan dari HP.

**Jangan bagikan file sesi (`.session`) ke siapa pun. Jangan deposit.**
