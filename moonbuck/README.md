# MoonBuck — @MoonBuckBOT

Bot Telegram gratis: undang teman + tugas + nonton iklan = USDT BEP20.

## Cara pakai (Termux)

```bash
pkg install git python -y
git clone https://github.com/buatgarapan69-pixel/skrip-garapan-konoha.git
cd skrip-garapan-konoha/moonbuck
pip install telethon
python3 moonbuck_umum.py
```

Isi dulu di bagian `KONFIG` dalam `moonbuck_umum.py`:
- `API_ID` + `API_HASH` — ambil di https://my.telegram.org/apps
- `WALLET` — alamat USDT BEP20 kamu (contoh: `0x...`)
- `REF_CODE` — ID Telegram pengundang (angka saja, boleh kosong)

Saat pertama jalan, login pakai nomor HP Telegram kamu + kode yang dikirim
Telegram. Semua langkah lewat menu bernomor di dalam skrip (1 perintah).
