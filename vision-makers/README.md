# Vision Makers (VMKS)

Mini App AITECH — kumpulin poin buat airdrop VMKS. Gratis, tanpa deposit.

- Daily Box hari 1: 10.000 koin
- Tap Tap: 1 koin per tap
- Undang teman: 5.000 koin per teman
- Airdrop VMKS belum dibuka, payout belum terbukti.

## Cara pakai

```bash
pip install telethon requests
python3 vm_umum.py
```

Buka file-nya dulu, isi API_ID + API_HASH kamu (dari https://my.telegram.org/apps).
REF_CODE boleh dikosongkan (atau isi kode referral teman kamu).

Login pakai nomor HP Telegram kamu + kode dari Telegram.
